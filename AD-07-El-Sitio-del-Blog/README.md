# AD-07 - El Sitio del Blog

Proyecto grupal de Desarrollo de Aplicaciones - Generation.

## Objetivo
Crear un sitio web tipo blog utilizando HTML y CSS.

## Metodología
SCRUM, con organización de tareas mediante un Backlog en GitHub Projects.

## Páginas del sitio
- Inicio
- Quiénes somos
- Contacto

## Actividades
1. Configurar el repositorio.
2. Crear el Backlog.
3. Crear el menú de navegación.
4. Crear el pie de página.
5. Diseñar la página de inicio.
6. Crear la página Quiénes somos.
7. Crear la página de contacto.

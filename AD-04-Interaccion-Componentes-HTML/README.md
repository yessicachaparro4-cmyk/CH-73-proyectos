# Burger Town 🍔

## Laboratorio AD-04: Interacción con Componentes HTML

Proyecto desarrollado con HTML, CSS y JavaScript.

### Funcionalidades
- Mostrar una alerta al hacer clic en COME TO BURGER TOWN!
- Mostrar un mensaje en la consola al hacer clic en Burger Town!
- Mostrar una imagen de hamburguesa.
- Cambiar el color del título a rojo al hacer clic en RICE!!
